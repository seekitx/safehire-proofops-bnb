# 英文界面与暖白深绿重设计

用户要求网站不出现中文，并明确选择 baoyu-design 的暖白加深绿方向。设计稿位于 `designs/safehire-marketplace-refresh/`，未放入忽略规则。

## 实现范围

- 统一现有 11 个页面的排版、导航、按钮、表单、状态和移动端样式。工作台重新安排为选择服务、保存订单、查看结果三个区域。
- 卡片集中显示费用、范围和当前报价状态；不把签名样例通过写成实际购买成功。完整限制可展开查看。
- 替换 411 项原中文界面、错误提示、行动准备和 Bark 文案，日期明确使用英文地区格式。
- 对照实验界面使用独立英文题目译本；原始中文任务快照及原始人工记录不改，下载记录另记实际展示的英文题目，避免改写历史实验。
- 证据页将本人评价标为英文翻译；原始证据文件、历史视频与正式提交回执保持原样。研究文档可继续使用中文，网站产品界面使用英文。
- 钱包逐步确认、签名校验、价格上限、提醒授权和订单状态转换没有放宽。

## 检查

- Python 417 项测试通过；类型检查、代码检查、安全扫描通过。既有通知测试同步更新英文验证码前缀。
- 11 个页面分别以桌面 1440px 和手机 390px 检查，全部返回成功，无页面脚本错误、横向溢出或可见中文。四类切换均检查。此检查不等于重新执行钱包付款。
- 修复旧全宽输入样式导致手机购买页的确认框挤压说明文字的问题。
- 设计预览使用实际界面快照，明确标记不是当前报价；真实购买与监控以线上工作台为准。
