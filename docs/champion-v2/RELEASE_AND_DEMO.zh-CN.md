# 发布、安全与评委演示

## 1. 发布前的止损线

你已经提交一版，优先保持提交链接可用。不要未经回归就替换主入口或原钱包流程。先单独部署 feature branch，确认新增路由可用，再把同一参赛条目的链接/视频更新；官方要求每队一个 entry，不应为了 V2 创建相互冲突的重复作品。[活动页](https://www.bnbchain.org/en/hackathons/smart-money-era)

本轮没有远程push、修改你线上容器、申请新权限、签名、授权、转账或请求付费服务。

## 2. 推荐灰度

默认 SAFEHIRE_ARENA_ENABLED=false、SAFEHIRE_PROVIDER_QUOTES_ENABLED=false：先验收匿名参考预览和合成引导。开启私有任务前准备持久存储、访问控制、配额、备份和隐私告知；开发数据库不可共享成公开静态资源。

建议完整应用先单worker验收，SQLite文件位于持久卷，不要多副本挂同一NFS假装高可用。任务存在数据库，报价熔断/并发控制是进程本地；大流量要迁移集中式配额、数据库和队列。本轮没有实现分布式调度/租户鉴权。

任务访问 token 仅有该本地记录的读写能力，不是钱包签名。浏览器保存在内存，刷新页面会丢失；离开前导出，导出文件不含 token。任务中不要存私钥、助记词、密码和敏感个人数据。导出是私密输入和结果，不要直接放公开 GitHub。

## 3. 威胁边界

| 情况 | 当前行为 | 上线仍需 |
|---|---|---|
| 旧任务/旧快照的方案 | task/snapshot不匹配或TTL过期拒绝 | 数据源认证与块重组处理 |
| 重试/并发覆盖 | 原文幂等＋version＋事务 | 生产压测、分布式部署方案 |
| 自称“已付款/已核验” | extra字段拒绝；caller_import不升级证据等级 | 与可信链上验证器的认证桥接 |
| 其他任务token读取 | 统一404，不泄漏任务是否存在 | 上层真实用户鉴权与授权 |
| 大请求/深JSON | 64000字节和64层限制 | 网关超时、速率限制、抗慢请求 |
| 整个DB被管理员替换为旧版 | 本地hash链不能单独发现 | 在独立位置保存最新head；签名/外部锚定 |
| 恶意供应商网络地址 | 受审配置、域名限制、DNS检查、不跳转 | 出站ACL/DNS连接钉扎；目前未完全解决rebind |
| 宣称已受限执行/盈利 | Arena始终不生成交易、业绩声明为false | 真实合约/协议执行审核与记录 |

不能以隐藏某个API的按钮代替权限检查；生产开关和后端校验是两回事。Web3框架能启动不代表支付安全审计完成。

## 4. 三分钟演示脚本

**第一段：现有真实路径，约一分钟。** 打开已提交市场入口，显示真实可用性、技能范围和更新时间；选择真实服务，说明分析与执行的区别。没有真实付款证据时直接披露，不用合成hash补位。

**第二段：新增创新，约一分钟。** 在 `/arena` 选择 LP，点 Run synthetic walkthrough。强调这是本地测试输入。一个按tick间距和成本约束生成的方案通过，另一个不合法区间被拦截。切换 Grid/Yield/Health，一次点击即可说明止损、容量、压力偿债判断，不要求评委操作JSON。

**第三段：记录可复核，约一分钟。** 在提前准备的真实交付（若尚没有就明确说本地参考）上展示任务hash、输入时间、精确输出、验证失败理由；导出私有bundle并运行离线校验。说明当前导出只能证明记录一致性，不能证明链上状态或供应商独立性。

最有说服力的后续版本：同一个真实金融任务，两个真正不同运营方的服务，交付前事先约定验收，交付后清楚解释哪个满足需求。不要把“两个本地方案”说成已经实现了这一步。

## 5. 回滚

应用脚本会打印类似：

```bash
python3 /解压位置/SafeHire_BNB_Champion_V2_2026-09-06/apply_overlay.py \
  /你的仓库 --rollback /你的仓库/.data/champion-upgrade-backups/实际时间目录
```

回滚再次核对当前文件和备份哈希；检测到后续编辑会拒绝，不能强制抹去。脚本回滚源码，不删除运行期间的数据库或真实证据，不重置 Git 分支，不会回滚链上状态。应用或回滚失败都应先查看输出，不要复制覆盖整个仓库。

## 6. 实际浏览器验收边界

本轮原生 Chromium 请求回环地址被运行环境策略拒绝（ERR_BLOCKED_BY_ADMINISTRATOR）。随后以浏览器实际执行页面JS、通过显式绑定调用真实隔离ASGI路由完成桌面和手机测试。截图顶部写明 OFFLINE BROWSER + ASGI / SYNTHETIC；没有把它包装成公网部署截图。

你自己的机器可重新运行原生HTTP版：

```bash
PYTHONPATH=src python scripts/arena_browser_smoke.py --output .data/arena-browser
# Chromium访问受限环境才使用以下模式：
PYTHONPATH=src python scripts/arena_browser_smoke.py --offline-asgi --output .data/arena-browser-offline
```

两个模式均不请求真实供应商、不测试钱包。完整公开部署、不同设备、Cookie/HTTPS/反代、原雇佣/撤销/退款必须另验。
