# 服务工作台与真实供应商适配

## 本轮交付范围

1. ChainHelix #269224 独立输入适配：绑定指定钱包、0.5 U、BSC、既有 Commerce/Router/Policy；不改变旧 0.1 U 订单。新的站内网格表单只传递当前供应商实现的计算字段。每笔交易仍由用户在钱包逐步确认。
2. 订单服务器跟进：私有凭证隔离，SQLite 持久化，重启租约恢复；显式同意才通知供应商，全局同一个订单最多三次且间隔五分钟；没有私钥或自动转账路径。
3. 网格验收：精确任务、价格、方向、档数、资金总额、数量重算；通过不等于盈利或策略执行，也不会自动放款。旧 Arena 四类约束验收保持原样。
4. 四类只读持续服务：BNB/USDT LP 越界、固定池网格价格范围、Venus Core 借贷阈值、两种 Venus 利率扣成本比较。目标约五分钟检查，持续 24 小时；原始观察带块与来源。读取失败为风险未知，历史数据不会替代新观察。
5. 站内提醒区分未读和已读，可暂停、下载使用记录；不声称手机推送或独立质量评价。工作台恢复凭证仅有本地记录访问权限，不代表钱包所有权。
6. 同任务报价入口明确显示不兼容的任务，只有已验证报价才展示有效费用；不编造两家可比较的交付或成功率。
7. 本人评价包含有用程度、原话、是否 AI 辅助及再次购买意愿；身份未独立认证，不计入盲评。
8. 调研文档迁入 `docs/research/`，`.gitignore` 显式保留 docs 可追踪。私密原始参与人记录、恢复凭证、数据库不公开。

## 支付边界审查

新增的可购买对象仅 #269224 与已核验钱包，价格固定审核上限 0.5 U；任何不同价、币、链、签名域或注册钱包都必须失败。新建订单沿用既有期限计算与乐观争议策略，不把报价预计时间当退款期限。跟进步骤以链上实际状态恢复，不重复创建或付款。原始 ChainHelix #56741 是供应商站点购买的已提交结果，不能改写为新版本站内购买已经实测。

## 部署

- `SAFEHIRE_FOLLOWUP_ENABLED=true` 开启服务器跟进；关闭时 API 明示不可用。
- `SAFEHIRE_FOLLOWUP_DB=/app/.data/followup.sqlite3` 必须在持久卷中。
- 保留原主网购买开关及每笔钱包确认。单实例运行，SQLite 事务租约避免重复领取；不声称多区域高可用。
- 日志读取使用 `SAFEHIRE_BSC_LOG_RPC`，默认公共 BSC 日志节点，每次最多 1000 块；不是改变签名或资金权限。
- 本机代理网络可能将公网域名解析成内部地址，此时交付抓取正确拒绝；不能为联调关闭 SSRF 检查，应在真实服务器验证。

## 容量和限制

最多 500 个工作台、共 200 条任务，每个工作台最多 10 条。每条保留最近 300 条事件；导出明确记录上限。监控与告警是自营只读服务，不能替代官方四类自动策略执行。暂停对后续检查生效，已进行的只读请求可能保存最后一次观察。没有第二位独立人工评阅人，三组无 AI 对照来源另有待复核提示。
