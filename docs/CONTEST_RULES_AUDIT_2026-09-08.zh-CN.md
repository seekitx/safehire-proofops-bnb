# BNB Build the Era 官方规则核查（2026-09-08）

结论：主赛比的是“让陌生人找得到、看得懂、用得上真实 Agent 的市场”，不是功能数量，也不是钱包看板。四类同等深度、真实数据、完整使用过程是当前公开评分重点；不能据此计算夺冠概率。

## 主赛：硬性条件与评分分开看

- 资格：每队一个作品；评审期公开可用；所展示 Agent 须在 BSC 上真实运行。
- 评分：功能完整、数据质量、Agent 多样性；未公布数字权重。再平衡、网格、收益优化、健康因子四类需要同等深度。
- 先公布前三名入围；第二阶段标准尚未公开。因此不能把当前规则当作全部终局规则。

来源：[官方赛事页](https://www.bnbchain.org/en/hackathons/smart-money-era)。

## 合作伙伴奖项独立判断

- **TermiX**：必须提供 Agent Advantage Report：至少三项真实任务，分别走市场雇 Agent 和不雇 Agent 两种方式，附时间、成本、质量和原始输出；至少一项属于交易、股票或安全。四项权重为服务价值 30%、实证优势 30%、高风险类别及记录 20%、市场体验 20%。不要求接 TermiX 接口，评委会亲自雇用。
- **PancakeSwap**：必须对其交易者或流动性提供者有实际好处；不是挂个品牌或读取钱包就符合。
- **Altana**：要求其浏览器可见的真实链上交易，测试网也计；有受限会话和可撤销权限。不要把它的交易资格条件误写成主赛统一条件。

来源：[官方赛事详细规则](https://www.bnbchain.org/en/hackathons/smart-money-era?tab=tracks)。

## 冲冠建议，不是官方硬性数量要求

让一名陌生用户完整完成找 Agent、比较、雇用、收取真实结果及核验；四类各有可复查样例；加入第二个独立供应商以证明市场不是单一供应商门面；用非零真实仓位检验数据与建议；部署同一候选版本、准备简短连续演示并留存提交回执。这些是对公开评分的工程推论，不是官方额外门槛。

真人盲评、第二供应商、“每类一笔主网支付”、特定 release tag 都未在本轮读取的主赛规则中列为硬条件。可以作为增强证据的方法，不可承诺做完便夺冠。钱包查币功能可以作为入口，但不能代替四类金融 Agent 的真实使用结果。
