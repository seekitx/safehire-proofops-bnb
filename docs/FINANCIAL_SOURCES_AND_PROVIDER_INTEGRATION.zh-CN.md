# 金融数据与供应商联调：已实现范围和真实缺口

日期：2026-09-07。只读操作，没有连接用户钱包、签名、支付或通知供应商执行收费任务。

## 已实现的数据链路

Arena 页面增加 Venus 模板和只读创建入口：先确认预算、迁移费用、容量等假设，再读取真实利率并创建私有任务。可选填公开钱包地址，不接收私钥。原有手动任务仍是调用者提供的数据，不会因增加这个入口变成可信证据。

`POST /api/arena/source-tasks/venus-yield` 接收 `template`、`current_venue`、可选 `account` 和显式同意标记。沿用 Arena 部署开关，最多同时采集两个请求，45 秒超时；失败不填示例数字，也不创建替代任务。

目前限定 Venus core USDT、USDC 两个已审市场，不是所有协议或全账户扫描：

- 在 BSC 主网最新高度后退 12 块固定采集区块；所有合约读取指定相同区块哈希，结束后重新检查是否仍在主链。
- 读取底层代币、精度、协议控制合约、每块供应利率、最近计息区块；固定市场与代币匹配，不接受用户任意地址作为数据源合约。
- 指定账户时读取 vToken 余额、已记账借款、已记账兑换率，并用整数换算存款原始单位。它们是协议存储值，不声称已经补计所有利息。
- 用 1200 块的实测时间窗口估算年化，不套用旧版固定出块常数。使用每日复利、365 天、当前利率持续不变的假设；不含奖励、税、汇率变化、脱锚和换币损失，不是历史收益或保证收益。
- 保存原始请求、响应、区块和计算方法；来源观察随任务创建原子写入私有记录，导出时可检查内容摘要与区块绑定。来源摘要只能辅助发现内容变化，不能替代独立节点或链上证明。
- 自动替换任务中的利率和区块；不擅自把用户资金、费用、可提现容量和等待期标成已验证。`financial_inputs_authenticated=false`、`settlement_authorized=false` 保留。

读取范围没有覆盖完整债务、账户所有权、价格预言机、清算阈值、隔离池、LP 仓位及网格成交成本。不得把两市场存款当成用户总资产，不得把“未看到债务”当成“没有债务”。

## 供应商联调结果：被明确阻挡，未算完成

向公开 Brain A2A 端点发送了 `negotiate` 报价请求，内容为不含用户地址的示例收益任务，同时要求完整 `safehire-proposal/2` 交付。未调用 `notify_funded`。

服务返回 `accepted: true` 和普通商业报价，但没有返回完整签名协商封套。当前验证器正确报错：

```text
QuoteVerificationError: live Agent did not return a complete signed ERC-8183 negotiation envelope
```

这不是已取得供应商签名，也不是供应商确认支持新格式。不能根据普通 `accepted` 字段就让用户付款。公开 Agent Card 的能力说明也没有证明 Arena 格式已支持。

可复查脚本：`scripts/probe_arena_provider.py`。它只发送不含私人仓位的示例报价请求；失败退出非零；成功也只标记报价兼容，交付验证仍为 false。脚本不纳入自动网络测试，防止日常检查反复请求供应商。

对方需要补齐：

1. 返回现有 SafeHire 验证器要求的签名报价，精确绑定请求、完整任务、交付条款、链、合约、币种、金额和到期时间。
2. 明确支持 `schema_version=safehire-proposal/2`；返回精确 agent_ref、task_hash、snapshot_hash、action、parameters。任务与快照摘要现已直接写进交付要求，避免对方猜序列化方式。
3. 提供按该任务生成的真实结构化交付及原文承诺；先以对方提供的联调样本核对协议。收费主网闭环另需用户审核金额和钱包签名，不能由这个只读探针代替。
4. 新格式期限必须覆盖任务快照的有效期；不允许交付后通过改时间或换快照让旧结果过关。

## 验证与下一步

新增回归用例覆盖错链、重组、错误账户、协议错误码、非零尾随数据、年化时间窗、不可伪装的市场范围，以及来源与导出绑定。遵守全局规则：本地未编译、未运行测试套件；仅做静态检查和用户本次要求的实际只读接口联调。

要继续验收用户的非零真实仓位，需要公开 BSC 钱包地址及所用协议。要打通供应商交付，需要供应商配合上述协议，不能单方面伪造签名或把旧文章转写成供应商的新交付。
